# nuwax-upload

Upload files and directories to MinIO (S3-compatible) storage, from the command line.

This is the npm distribution of the Rust binary. Each platform gets its own
native binary via an optional dependency — no compilation, no GitHub download.

## Install

```bash
npm install -g nuwax-upload
# or use without installing:
npx nuwax-upload <PATHS>...
```

## Usage

```bash
nuwax-upload [OPTIONS] <PATHS>...
```

Full documentation, parameters, and examples live in the
[project README](https://github.com/nuwax-ai/nuwax-upload#readme).
